Introduction

Welcome to your new book! This chapter is a plain HTML file in the content/ folder. Replace it with your own words.

How chapters work

A chapter is a fragment of XHTML: just the content, without <html>, <head> or <body>. bkr wraps it in a complete page and adds your stylesheets and scripts when you run book build.

XHTML is a little stricter than everyday HTML:

  • close every tag, including <p> and <li>;
  • close empty elements too: <br/>, <img src="..." alt="..."/>;
  • write ampersands as &amp;, as in “Salt & Pepper”.

The first <h1> is the chapter title unless config/book.yml gives one.

Adding chapters

Create a new file in content/, for example 03_next_steps.html, then list it under chapters: in config/book.yml so it shows up in the right place.
